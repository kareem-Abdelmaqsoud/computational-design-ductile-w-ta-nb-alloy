# UMA model versions: notes for this work

**Decision:** elastic properties use `uma-s-1p2p1` (OMat task) with strains capped at 1%,
and the standard Pugh ratio K_VRH/G_VRH. Data are generated by `generate_uma_elastic_data.py`.

## 1. `uma-s-1p1`: C44 too low, hidden by large shear strains

- With small shear strains (≤1%), 1p1 gives pure Nb a C44 of **8.1 GPa**, against **18.3 GPa** from DFT. This is
  why the earlier work switched to the C′-based ratio 2K/(C11−C12).
- With the older ±6% shear strains, 1p1 gives Nb a C44 of 19.9 GPa, so the error was masked by the
  large-strain fit.
- 1p1 also underestimates C′ = (C11−C12)/2 for Ta-rich alloys (40.5 vs 62.3 GPa from DFT at 10% W).

## 2. `uma-s-1p2`: not size-extensive, so don't use it

- The mixture-of-experts routing uses a composition embedding averaged with
  `index_reduce_(..., reduce="mean", include_self=True)`. This divides by N+1 instead of N, so the same
  crystal gets different expert weights depending on how many atoms are in the cell.
- fairchem-core 2.23 labels this in the source (`models/uma/escn_moe.py`): *"UMA 1.2 bug: including
  the zero-initialized self value in the mean breaks composition extensivity."* The Hugging Face model
  card recommends `uma-s-1.1` or `uma-s-1.2.1`.
- Effect on perfect bcc Nb at a = 3.31 Å (fairchem 2.21, default inference settings):
  - E/atom changes by **15 meV/atom** across cells of 1 to 128 atoms (1p1: < 0.001 meV).
  - C44 at 1% shear is **29.0 / 12.5 / 20.9 GPa** for 2- / 16- / 64-atom cells (1p1: 8.3 / 8.1 / 8.1).
- In fairchem 2.23, the default inference settings merge the expert weights on the first structure
  evaluated ("UMA fast path (merge_mole)"). In our tests, 1p2 Nb then gave the same C44 (33.1 GPa) at every
  cell size, which matches the first-evaluated (1-atom) cell. So 1p2 results can also depend on evaluation
  order and fairchem version.

## 3. `uma-s-1p2p1`: fixes the size problem (needs fairchem-core ≥ 2.22)

- Size-consistent: E/atom, stress and elastic constants are the same for 1- to 128-atom cells.
- Pure elements at 1% strains, values in GPa:

  | | C44 DFT / 1p1 / 1p2p1 | G DFT / 1p1 / 1p2p1 | K/G DFT / 1p1 / 1p2p1 |
  |---|---|---|---|
  | Nb | 18.3 / 8.1 / **17.5** | 29.1 / 15.3 / **29.5** | 6.34 / 10.42 / **6.26** |
  | Ta | 78.3 / 65.8 / 65.3 | 67.1 / 51.6 / 58.7 | 3.00 / 3.66 / 3.43 |
  | W | 165.4 / 143.8 / 133.4 | 169.3 / 150.8 / 153.6 | 1.96 / 2.02 / 2.07 |

- Mean absolute error against DFT on the nine 10%-Nb, 10-atom SQS cells (same cells as DFT):

  | | C44 | C′ | G | K/G |
  |---|---|---|---|---|
  | 1p1 | 7.5 | 15.0 | 7.9 | 0.31 |
  | 1p2p1 | 8.2 | 10.7 | 6.5 | 0.24 |

- Known limitations:
  - W's C44 is underestimated by about 32 GPa.
  - Like 1p1, it doesn't reproduce DFT's K/G maximum at 40–50% W (2.92 / 2.75 against 3.46 / 3.40 from DFT).

## Settings and environment

- Strains: normal and shear ±0.5% and ±1%. DFT reference: VASP `IBRION=6`, `ISIF=3`, `POTIM=0.01`.
- `uma-s-1p2p1` needs fairchem-core ≥ 2.22, which needs torch 2.13. The node's driver supports CUDA ≤ 12.8, so use the cu126
  build. Environment: `kabdelma/envs/fairchem223`, Jupyter kernel "Python (fairchem 2.23, UMA 1p2p1)".
- The older environment `kabdelma/envs/fairchem` (fairchem 2.21) has only 1p1 and 1p2.
